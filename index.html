SPORE — signed attestation API

Per-call Ed25519 attestations for any payload. Pay per call in 0.005 USDC on Base over x402 (HTTP 402).

Live endpoint: https://spore-x402.spore-x402.workers.dev/x402/attest

Spec: /openapi.json · Health: https://spore-x402.spore-x402.workers.dev/x402/attest

Payment: USDC on Base (eip155:8453), scheme exact, payTo 0xA29bfdB1fC8436D0643876c6B02A0B0bd45B7E79, amount 5000 atomic units (0.005 USDC), EIP-712 domain USD Coin v2.

Call it

1. GET https://spore-x402.spore-x402.workers.dev/x402/attest → HTTP 402 with a base64 PAYMENT-REQUIRED header.

2. Pay 0.005 USDC on Base, retry with PAYMENT-SIGNATURE (x402 v2) or X-PAYMENT (settled tx hash).

3. Success returns {attestation, canonical, sig, pubkey, verify} — verifiable offline against the returned public key.
